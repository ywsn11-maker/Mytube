YouTube Data API 키

API 키는 어디서 받나요? 1) Google Cloud 콘솔에서 새 프로젝트 생성

3) 좌측 메뉴 사용자 인증 정보 → API 키 만들기
4) 발급된 키를 위 칸에 붙여넣고 저장
무료 할당량 안에서 개인용으로 쓰기에 충분해요. 키는 이 브라우저에만 저장되고 구글에만 전송돼요.
